📋 Features Built

🔐 Safety & Verification

  • Two-layer child pickup safety (codes + teacher verification)
  • Photo verification — driver selfie + kid pickup photos
  • Trigger-based selfie checks (admin flag, new driver, 7-day interval)
  • Kid names hidden until driver arrives at school
  • Phone number masking for parents & drivers
  • Photo compression (sharp/libvips — ~50KB per photo)

🚕 Booking & Matching

  • Driver quote negotiation (school trips + all taxi/bus bookings)
  • Generic QuoteRequest system for non-school taxi/bus
  • Per-head pricing (auto-calculated per kid)
  • Vehicle types: car, boda, taxi, bus (no tuk-tuks)
  • School fleet management (My Fleet + Book External)
  • Capacity enforcement with hard seat limits

💰 Payments

  • Flutterwave integration (MoMo + card)
  • Per-kid payment tracking
  • Driver payouts with 5% PoleSafe commission
  • Credit system (sick day credits, early pickup credits)
  • Fuel adjustment pricing engine

👨‍👩‍👧‍👦 Mobile Apps

  • Parent app (booking, tracking, sick day, early pickup)
  • Driver app (route, earnings, safety codes, status updates)
  • School admin dashboard (broadcasts, gate check, detention)
  • Day/night theme with GlassCard design system
  • Loading states, empty states, form validation

📱 Accessibility

  • SMS command handler for feature phone parents
  • Africa's Talking SMS integration
  • WhatsApp notification channel
  • Attendance tracking (PoleSafe + non-PoleSafe kids)
  • Driver reliability spec (3-strike system, favorite drivers)
