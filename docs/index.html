🚀 All Features (A-Z)

👨‍👩‍👧‍👧 Add Child

  • Register kids with name, class, photo, medical info
  • Age-based safety (car seat flags)
  • Sibling linking for staggered pickup

📊 Attendance Report

  • Track PoleSafe + non-PoleSafe kids
  • Daily attendance per school
  • Status per child per day

📢 Broadcasts

  • School admin sends announcements
  • Target parents, drivers, or both
  • SMS + WhatsApp fallback

💳 Credits

  • Sick day credits when child misses school
  • Early pickup credits
  • Auto-apply to future bookings

🎨 Design System

  • GlassCard + PrimaryButton components
  • Day/night theme support
  • Uganda-inspired color palette

🕵️ Driver Vetting

  • PoleSafe driver ID (PS-DRV-XXX)
  • ID badge photo verification
  • Driver approval workflow
  • Selfie verification (trigger-based)

💰 Earnings

  • Driver earnings breakdown
  • School rides vs ride-hailing split
  • Date range filtering

⛽ Fuel Adjustment

  • Dynamic pricing based on fuel costs
  • Fuel price tracking from Energy Ministry
  • Auto-applied multiplier to fares

🚪 Gate Check

  • School gate confirms each child's departure
  • Driver code verification at gate

🗺️ Live Tracking

  • GPS coordinates on ride start
  • Tracking log with timestamps
  • Real-time driver location

📸 Photo Verification

  • Driver selfie on ride acceptance
  • Kid pickup/boarding photos
  • Sharp compression (~50KB per photo)
  • Trigger-based checks (admin flag, 7-day expiry)

📱 Phone Masking

  • Parents get masked IDs (not real numbers)
  • Drivers get masked contact
  • 24-hour auto-expiry
  • Admin can resolve if needed

💰 Payments

  • Flutterwave integration (MoMo + card)
  • Per-kid payment tracking
  • 5% PoleSafe commission on third-party trips
  • Payment status per child

🚕 Quote System

  • Drivers quote prices for school trips
  • Generic QuoteRequest for any taxi/bus booking
  • Per-head or flat-rate pricing
  • Admin accept/counter workflow
  • Fleet vehicles skip quoting (direct assign)

🏁 Ride Statuses

  • Flow: scheduled → en_route → picked_up → dropped_off → gate_confirmed → completed
  • Driver updates via app
  • Timestamps for each transition
  • Cancel/missed handling

🚸 Safety

  • Two-layer pickup safety (daily codes + teacher verification)
  • Kid names hidden until driver arrives at school
  • Pickup codes for each ride
  • Classroom pickup verification by teacher

🏫 School Fleet

  • School-owned vehicles with bus labels
  • My Fleet tab (own buses)
  • Book External tab (third-party drivers)
  • Capacity enforcement (max seats)

📱 SMS for All

  • SMS command handler for feature phones
  • Africa's Talking integration
  • WhatsApp as primary channel
  • SMS templates in English + Luganda

🏫 School Tours

  • School trip lifecycle (draft → open → confirmed → in_progress → completed → cancelled)
  • Per-head pricing
  • Driver quote negotiation
  • Kid list privacy (revealed on arrival)

👩‍🏫 Teacher Verification

  • Classroom teacher verifies driver at pickup
  • Second safety layer (Layer 2)
  • Teacher screen for pickup verification

📚 Schema (12 Models)

User — Parent, Driver, or School Admin
Child — Kid profile linked to parent
School — School registration
Vehicle — Car, boda, taxi, bus (no tuk-tuks)
Ride — Individual ride booking
Booking — Weekly/monthly/termly subscription
Transaction — All payment records
Credit — Sick day / early pickup credits
Broadcast — School announcements
SchoolTrip — Tour/trip system with full lifecycle
QuoteRequest — Generic taxi/bus quote negotiation
Attendance — Daily attendance tracking
FuelPrice — Fuel cost tracking for dynamic pricing
